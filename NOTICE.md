# Notice

Rovr is an independent architectural fork/reimplementation inspired by
[yabai](https://github.com/asmvik/yabai), originally created by Åsmund Vikane.
Yabai is distributed under the MIT License.

The initial Rovr bootstrap intentionally does not copy Yabai implementation
files. The macOS platform boundary is designed so battle-tested Yabai private
API and scripting-addition techniques can be ported behind a narrow C ABI.
When upstream source is incorporated, its copyright and license notice must be
preserved in the relevant files and distributions.
